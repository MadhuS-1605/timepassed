# Store Listing — ASO Copy (App Store + Play Store)

Ready-to-paste, keyword-optimized listing copy for both stores. ASO is search:
the title/subtitle/keywords carry the most ranking weight, so the highest-value
terms ("year progress", "life calendar", "habit tracker", "focus timer",
"mood tracker", "memento mori") are front-loaded.

Update these whenever the feature set changes, then refresh screenshots.

## Screenshot strategy (both stores)

Order sells the *feeling* first — lead with the visual hook, not a feature list.

1. **Hero** — Year progress grid filling up, big % + tagline "See your year, second by second."
2. **Life in weeks** — the memento mori grid (emotionally striking, highly shareable).
3. **Daily Pulse heatmap** — the colorful year-of-moods grid.
4. **Live wallpaper** — phone mockup showing the wallpaper on a lock screen.
5. **Yearly Wrap** — the shareable recap card.
6. **Widgets** — home screen with the widgets pinned.

Tips:
- First 2 screenshots are what most users see — make them the strongest.
- Add a short caption banner on each (the store crops/blurs otherwise).
- Localize captions if you target non-English stores.

## A/B testing
- Play Console: use **Store Listing Experiments** to A/B the icon, short
  description, and first screenshot.
- App Store: use **Product Page Optimization** to test up to 3 screenshot sets.

## Review prompts
Ask for a rating at a peak emotional moment — right after a user generates their
**Yearly Wrap** or hits a **7-day streak** — not on a cold launch. Use
`StoreReview` (iOS) / In-App Review API (Android), capped to the OS-allowed
frequency.
